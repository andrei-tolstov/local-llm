# Тесты шума/охлаждения Tesla V100 (пассивная, вентилятор на SFAN3/CPU_FAN)

## Контекст (замерено на хосте)
- GPU 0: Tesla V100-PCIE-32GB, пассивная. Охлаждение — серверный вентилятор в каналах NCT6779 `pwm2` (CPU_FAN) + `pwm3` (SFAN3), инвертированная логика: 255 = минимум, 0 = 100%.
- Пороги GPU (nvidia-smi -q -d TEMPERATURE): slowdown 87 °C, shutdown 90 °C, max operating 83 °C, HBM max operating 85 °C.
- Текущая кривая v100-fancontrol.py: 48–58 °C → PWM 90 (~64 %), 58–68 °C → PWM 50 (~80 %). Именно 80 % на 60 °C — шумно.
- Idle сейчас: 46–49 °C при PWM 125–90 (50–64 %) + «качели» из-за отсутствия гистерезиса.
- Power scheduler: day 250 W + lock 1380 MHz, night 23:00 100 W + 495 MHz.

## Цель
Минимальные обороты (максимальный PWM), при которых под максимальной нагрузкой нет тротлинга, с запасом до порога. Если оборотами шум не убрать — снижать лимит мощности.

## Ограничения по времени
- Тесты закончить до 22:50 MSK (в 23:00 night timer ставит 100 W / 495 MHz). На время теста night/day таймеры приостановить, затем вернуть.

## Безопасность
- Не трогать docker/containerd, инфраструктурные контейнеры.
- Защита: GPU ≥ 84 °C или CPU package ≥ 78 °C → сразу PWM 0 (100 %), точка теста прекращается.
- В finally: безопасный ШИМ + возврат сервиса v100-fancontrol + режим day (250 W / 1380 MHz).

## Результаты (итог)

**Главное:** настоящий троттлинг начинается при **82 °C** (`sw_thermal_slowdown`), а не при 87 °C
из `nvidia-smi`; ниже 30 % duty карта теряет ~55 % производительности (1380 → 700 МГц).

**Новая кривая** (`scripts/v100_fancontrol.py`, развёрнута в `/usr/local/bin/v100-fancontrol.py`):
простой 19.6–27.5 %, инференс 33–41 %, пик 45–53 %, аварийно 100 % с 80 °C. Гистерезис 4 °C,
выдержка 150 с, учёт HBM2, потолок по CPU, fail-safe 53 % при остановке, старт по текущей температуре.

| Режим | Обороты было | Обороты стало | Температура | Δ шума (оценка, L~n^5) |
|---|---|---|---|---|
| Простой | 49–64.7 % (качели) | 19.6–27.5 % (стабильно) | 46–50 °C | −13 дБ |
| Реальный инференс (114 Вт) | 64.7 % | 33.3–41.2 % | 57.6 (max 59.0) °C | −14.6 дБ |
| Пик GEMM (151 Вт) | 80.4 % | 45.1 % | 65.1 (max 66.0) °C, 1380 МГц, без троттлинга | −12.4 дБ |

Мощность лимитировать не пришлось: на фиксированных 25.5 % duty даже PL 120 Вт даёт 81 °C,
а PL 150 Вт вообще не задействуется (реальное потребление GEMM 143–146 Вт). Подробно:
`power_and_optim/report_fan_noise_tuning.md`.

**Инструменты, оставшиеся в репозитории:** `scripts/gpu_fan_sweep.py` (ступени ШИМ + стационар
+ защита + `--monitor-only`), `scripts/llm_load.py` (реальный инференс-прогон),
`scripts/gemm_bench.cu` (теперь с размером матрицы в аргументе).
